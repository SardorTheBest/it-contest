# IT-Квест

## Локальный запуск

Нужен Node.js 18.17 или новее. Создайте новый ключ Google AI Studio:

```powershell
$env:GEMINI_API_KEY = "ВАШ_НОВЫЙ_КЛЮЧ"
npm start
```

- `http://localhost:3000` — экран участника (выбора роли нет).
- `http://localhost:3000/?host` — экран ведущего, без пароля.

Роль ведущего закрепляется за первым устройством, открывшим `?host`. Другое устройство получит ведущего, только если первое молчит 10 минут.

## Развёртывание в Vercel

Импортируйте GitHub-репозиторий в Vercel и добавьте секретные Environment Variables:

- `GEMINI_API_KEY` — новый ключ Google AI Studio;
- `KV_REST_API_URL` и `KV_REST_API_TOKEN` — REST URL и токен базы Upstash Redis, подключённой к Vercel-проекту (интеграция Upstash автоматически добавляет эти переменные).

Redis обязателен на Vercel: он хранит общий этап конкурса, присутствие и очки между бессерверными запросами. Upstash Redis уже подключён к проекту через Vercel Marketplace. Используйте один экземпляр Node-сервера и не перезапускайте его до конца конкурса при локальном запуске.

## Сценарий конкурса

1. Откройте ссылку с `?host` на экране ведущего до начала конкурса. На устройствах участников откройте основную ссылку без `?host`: участники вводят только имя и аватар.
2. Ведущий запускает презентацию и раунды 1–3. При входе в каждый раунд участник автоматически получает случайное задание из 50 вариантов; задания не повторяются у него в рамках трёх раундов и сохраняются при перезагрузке страницы. Сайт показывает совет по промпту.
3. Ученик открывает генератор Bing, создаёт картинку, возвращается на сайт, вводит промпт и загружает изображение на оценку.
4. Gemini 3.5 Flash-Lite оценивает изображение по заданию и промпту. Баллы появляются на экране ведущего; после третьего раунда ведущий показывает итоги.

Советы для промптов встроены в сайт и не требуют внешнего AI-сервиса или аккаунта Claude. Ключ Gemini должен храниться только в Vercel Environment Variables и не добавляться в GitHub, исходники или чат. Изображения отправляются Google Gemini для оценки и не сохраняются сайтом. Перед использованием с детьми убедитесь, что передача работ Google соответствует правилам школы и требованиям согласия родителей.

Проверка локального сценария: `npm test`. Запросы к реальному Gemini требуют действительного `GEMINI_API_KEY`.
